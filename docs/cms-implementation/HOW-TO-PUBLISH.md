# How to change the websites: a plain guide

For everyone who edits the Acadvizen websites. No technical knowledge needed.

> **Which part of this guide applies today?**
> - **Section A (live now):** Main website text, blogs and settings are changed in **Acadvizen Master Admin → Main Website**.
> - **Section B (when switched on):** designing pages in **Elementor** with approval. It is ready but **not switched on yet**; the administrator will tell you when it is.

## Signing in

1. Go to **enroll.acadvizen.com/wp-admin**.
2. Sign in with **your own** account. Never share it.
3. Forgot your password? Click **Lost your password?**

---

## A. Changing the Main website today (live)

**Change a page:**
1. **Acadvizen Master Admin → Main Website → Pages**, then **Edit** the page.
2. Click **Prepare changes privately**. Visitors keep seeing the old page while you work.
3. Change the text or pictures. Click **Save section** under each part you change.
4. Click **Preview** and look at it on desktop, tablet and phone.
5. Happy? Set **Status** to **Published** and click **Save**.

**Write a blog:**
1. **Main Website → Blogs → Add new**.
2. Write it, then choose **Publish To**: Main, Enrollment, or Both.
3. Choose **Published** and **Save**.

**Undo a mistake:** open the page or blog, then **Earlier versions → Restore**.

The full guide is `ADMIN-USER-GUIDE.md`.

## B. Designing pages in Elementor, with approval (when switched on)

### The idea in one sentence

You design. A reviewer checks. Only then does it go live, on exactly the websites you chose.

```
 You design ──► You press "Publish" ──► Reviewer approves ──► "Publish approved revision" ──► Checked live ✔
               (this only SUBMITS)       (or sends it back)
```

### 1. Make or change a page

- **New page:** **Pages → Add New**, then **Edit with Elementor**.
- **Change a live page:** open it as usual. You get its **working copy** automatically: a private copy where you can work while visitors keep seeing the live page.
- **Design freely:** sections, columns, text, images, buttons, colours, and sizes for phone and tablet.
- **Click "Save Draft"** whenever you like. Nothing goes live.

### 2. Choose where it appears

In the page's **Publish To** box:

| Choose | It appears on |
|---|---|
| **Enrollment** | enroll.acadvizen.com |
| **Main** | www.acadvizen.com |
| **Both** | Both websites |

### 3. Submit it

- **Click "Publish" in Elementor.** It does **not** go live. It is sent to a reviewer as "Waiting for approval".
- **If it can't be sent,** a message explains why. For example, a widget the chosen website can't show (a shop button on Main). The message says how to fix it.

### 4. Wait for the reviewer

- **Approved:** it is ready to go live.
- **Rejected:** it comes back to you with a note saying what to change.
- **Changing anything after you submit** (even one word) means it must be approved again. That is on purpose: the reviewer approves exactly what they saw.

### 5. Go live

The reviewer (or you, if allowed) clicks **Publish approved revision**. Within a few minutes each chosen website is checked:

| You see | It means |
|---|---|
| ✔ **Verified** | It's live everywhere you chose |
| ⚠ **Partial failure** | One website has it and the other doesn't yet. That other website still shows the old version. Tell the administrator, or click **Check again** later |
| ✖ **Failed** | Nothing changed; the old version is still showing |

### Want it to go live later?

Before you click **Publish**, set the **publish date** in the page settings. The reviewer then sees **Schedule approved revision for …**. The page goes live by itself at that time, but only if nobody changed it in between. Times are in the website's time zone.

### 6. Go back to an earlier version

A reviewer can click **Restore** next to an earlier version in **Approvals**. It goes back live and is checked again.

### Things to remember

- **Only reviewers can change site-wide colours and fonts.** They affect every page on both websites.
- **Shop, cart and login widgets only work on the Enrollment website.**
- **Typed code** (HTML or shortcode widgets) needs a reviewer who checks the code.
- **Press a button once and wait.** Some steps take up to 20 seconds.

**Need help?** Ask your administrator. Reviewers have their own guide: `REVIEWER-GUIDE.md`.
